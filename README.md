# SKALA 자동 출결

SKALA 출결 인증을 자동화하는 프로젝트입니다. 플랫폼별로 작동 방식이 다르며, 아래 폴더에 대한 README의 메뉴얼을 따라주세요.

| 폴더 | 대상 | 설명 |
| --- | --- | --- |
| [`mac/`](mac/README.md) | macOS | 완전 자동으로 폼 입력·구글 인증까지 진행 + 정해진 시간에 자동 실행(기본값: 평일 오후 5시 49분) |
| [`android/`](android/README.md) | Android | 별도 앱을 설치해, 수동으로 앱을 열거나 갤럭시 루틴으로 정해진 시간에 이름·지역·반을 자동 입력. 구글 로그인 전 단계까지 자동 실행 |

각 폴더는 독립적인 프로젝트입니다 — 서로 코드를 참조하지 않고, 설치·빌드·실행도 완전히 따로 합니다. 사용하려는 플랫폼의 폴더로 들어가서 그 안의 README를 따라가면 됩니다.
