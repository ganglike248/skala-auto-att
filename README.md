# SKALA 자동 출결 (Android)

이름·지역·반을 자동으로 입력해주는 앱입니다. 구글 로그인은 등록해둔 계정을 탭 한 번으로 선택하면 되고,
출석 체크 버튼은 직접 눌러야 합니다. 갤럭시 루틴과 연결하면 실행 자체도 원하는 시간에 자동으로 됩니다 (아래 [자동화 하기](#자동화-하기-선택) 참고).

[skala-auto-att](https://github.com/ganglike248/skala-auto-att) (macOS/launchd 버전)의 안드로이드용 자매 프로젝트입니다.

---

## 빌드

```bash
./gradlew assembleDebug
```

결과물: `app/build/outputs/apk/debug/app-debug.apk`

## 설치 (사이드로드)

스토어에 올리지 않고 APK 파일을 폰에 직접 옮겨서 설치합니다.

```bash
# 폰이 USB로 연결되어 있고 개발자 옵션 > USB 디버깅이 켜져 있을 때
adb install app/build/outputs/apk/debug/app-debug.apk
```

또는 APK 파일을 카카오톡/이메일/드라이브 등으로 폰에 옮긴 뒤 파일을 열어 설치해도 됩니다.
(첫 설치 시 "출처를 알 수 없는 앱" 허용이 필요할 수 있습니다.)

## 설정

앱을 처음 열면 설정 화면이 뜹니다. 맥 버전의 `.env`에 해당하는 값을 입력합니다.

| 항목 | 설명 |
| --- | --- |
| 이름 | 훈련생 이름 |
| 구글 이메일 | 출결 인증에 쓸 구글 계정 (로그인 화면에서 이 계정이 자동으로 선택되도록 힌트로 사용됨) |
| 지역 | 드롭다운에서 선택 (예: `울산캠퍼스`) |
| 반 | 드롭다운에서 선택 (예: `4반`) |

우측 상단 톱니바퀴 아이콘으로 언제든 다시 수정할 수 있습니다.

## 자동화 하기 (선택)

**설정 > 모드 및 루틴 > 루틴**에서 '+'를 눌러 아래 두 루틴을 만듭니다.

### 출석 (평일 오전 8:50)

- **언제 실행할까요?(조건)****:** 특정 시각에 → 오전 8:50, 1일마다, 건너뛸 요일 선택(공휴일, 토요일, 일요일)
- **무엇을 할까요?(작동):** 연결 -> Wi-Fi -> 사용, 애플리케이션 -> 앱을 열거나 앱 동작 바로 실행 -> SKALA 출결 열기
- **반복 기한:** 계속 반복

### 퇴실 (평일 오후 5:50)(출석과 거의 동일)

- **언제 실행할까요?(조건):** 특정 시각에 → 오후 5:50, 1일마다, 건너뛸 요일 선택(공휴일, 토요일, 일요일)
- **무엇을 할까요?(작동):** 연결 -> Wi-Fi -> 사용, 애플리케이션 -> 앱을 열거나 앱 동작 바로 실행 -> SKALA 출결 열기
- **반복 기한:** 계속 반복

## 구조

- `MainActivity.kt` — WebView로 SKALA 사이트 접속, 자동입력 스크립트 주입, 구글 로그인은 커스텀 탭으로 위임 (이메일은 login_hint로 전달)
- `AutofillScript.kt` — `auto_att.py`의 Playwright 로직을 그대로 옮긴 JavaScript (이름 입력 → 지역 선택 → 반 선택 → "다음" 클릭)
- `SettingsActivity.kt` / `Prefs.kt` — 설정값 입력 화면(지역/반 드롭다운 포함)과 저장소 (SharedPreferences)
- `ClassOptionsFetcher.kt` — 설정 화면에서 지역을 선택하면 보이지 않는 WebView로 실제 사이트에 접속해 그 지역의 반 목록을 읽어옴
- `InsetsUtil.kt` — 엣지투엣지로 인한 상태바/내비게이션 바 겹침 방지, 상태바 아이콘 색 처리
