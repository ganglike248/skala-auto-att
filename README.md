# SKALA 자동 출결

SKALA 출결 인증을 자동화하는 프로젝트 모음입니다. 플랫폼별로 폴더가 나뉘어 있고, 각 폴더 안에 그 플랫폼 전용 README가 있습니다.

| 폴더 | 대상 | 설명 |
| --- | --- | --- |
| [`mac/`](mac/README.md) | macOS | Playwright로 Chrome을 직접 조종해 완전 자동으로 폼 입력·구글 인증까지 진행. `launchd`로 정해진 시간에 자동 실행 |
| [`android/`](android/README.md) | Android | 앱을 열면(또는 갤럭시 루틴으로 정해진 시간에) 이름·지역·반을 자동 입력. 구글 로그인은 계정 선택만 하면 됨 |

각 폴더는 독립적인 프로젝트입니다 — 서로 코드를 참조하지 않고, 설치·빌드·실행도 완전히 따로 합니다. 사용하려는 플랫폼의 폴더로 들어가서 그 안의 README를 따라가면 됩니다.

향후 iOS 버전을 추가하면 같은 구조로 `ios/` 폴더가 생깁니다.
